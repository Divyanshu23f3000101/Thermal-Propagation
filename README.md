# Thermal-Propagation
 Objective:-
This project studies heat propagation through different materials using multiple NTC temperature sensors and an ESP32 microcontroller.
 NTC sensors are placed at different positions along a rod to measure temperature changes over time.
 One end of the rod is heated, while the ESP32 continuously collects temperature data from all sensors.
 The data is displayed in real time through a local web server, including temperature graphs and heat distribution.
 The project helps analyze temperature gradients, heat transfer, and thermal conductivity while providing practical experience in IoT, embedded systems, and data visualization.
